## 🚀 Featured Projects

### 🛒 [V-CART — Full-Stack E-Commerce Platform](https://github.com/Vasu-Chourasia)

A MERN-stack e-commerce platform featuring voice navigation, an admin dashboard, and secure payment workflows.

**Key Features**
- 🛍️ Separate customer storefront and admin portal.
- 🎙️ Voice-controlled navigation using the Web Speech API.
- 🔐 Firebase OAuth and JWT authentication using HTTP-only cookies.
- ☁️ Multi-image uploads using Multer and Cloudinary.
- 💳 Integrated Razorpay and Cash on Delivery payment workflows.
- 🔄 Order synchronization with MongoDB.

**Tech Stack:** React.js, Node.js, Express.js, MongoDB, Firebase, JWT, Cloudinary, Razorpay.

### 💼 [Employ-Net — Full-Stack Job Portal](https://github.com/Vasu-Chourasia)

A full-stack job portal that allows recruiters to publish job listings and job seekers to search and apply for opportunities.

**Key Features**
- 🏢 Recruiter and job-seeker functionality.
- 🗃️ Normalized MySQL database with transactional operations.
- 🔐 JWT authentication, bcrypt password hashing, and role-based authorization.
- 🛡️ Input validation and HTML escaping.
- ☁️ Deployment on AWS.

**Tech Stack:** Node.js, Express.js, MySQL, JavaScript, JWT, CSS3, AWS.

### 🎓 Student Management REST API

A modular Spring Boot backend service for managing academic records, featuring dynamic filtering, server-side pagination, and centralized validation.

**Key Features**
- 🔌 REST endpoints with DTOs and standard HTTP status handling.
- 🔎 Multi-criteria filtering using JPA Specifications.
- 📄 Server-side pagination using `Pageable`.
- ✅ Centralized validation and exception handling with Jakarta Bean Validation and `@RestControllerAdvice`.
- 🛡️ Parameterized Criteria API queries and global CORS configuration.

**Tech Stack:** Java, Spring Boot, Spring Data JPA, Hibernate, MySQL, Docker, Maven, Swagger UI.
